Input: Nhập vào số nguyên n
Output: Kiểm tra số n có là số hoàn hảo không?

Ví dụ:

Input: n = 28


Output: kết quả trả về 1
(vì các ước của 28 mà không tính 28 là U(28)={1,2,4,7,14} mà tổng 1+2+4+7+14=28 nên thảo mãn điều kiện số hoàn hảo)

Input: n = 20


Output: kết quả trả về 0
(vì các ước của 20 mà không tính 20 là U(20)={1,2,4,5,10} mà tổng 1+2+4+5+10=20 khác 22 nên không thỏa mãn điều kiện số hoàn hảo)

Input: n = -9


Output: trả về 0 (vì n < 0)
